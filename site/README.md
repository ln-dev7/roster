# Roster — site

The presentation site for [Roster](../README.md), served at
[roster.lndev.me](https://roster.lndev.me).

Next.js (App Router) · Tailwind v4 · shadcn/ui (Base UI, `base-maia` style) ·
next-intl for the `/en` and `/fr` locales.

## Develop

```bash
pnpm install
pnpm dev
```

## Conventions

- Every UI component is added through the shadcn CLI
  (`pnpm exec shadcn add <name>`), never written by hand into
  `components/ui/`.
- All copy lives in `messages/en.json` and `messages/fr.json` — no strings
  in components.
- `DESIGN.md` is the design reference the page follows (structure, type
  scale, spacing); the palette is Roster's own blueprint identity, defined
  in `app/globals.css`.
- The hero animation (`components/site/hero-room.tsx`) mirrors the macOS
  app's real geometry and timings — the site shows the product, it doesn't
  fake it.
